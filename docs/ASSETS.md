# 자산의 출처와 사용 범위

| 자산 | 출처 · 범위 |
| --- | --- |
| PIP token/UI CSS | npm `@whitekiwi/tokens@0.2.1`, `@whitekiwi/ui@0.2.1`. MIT 고지를 `public/PIP-LICENSE.txt`에 보존하며 빌드에 포함합니다. |
| Toss 심볼 | [공식 심볼 다운로드](https://static.toss.im/assets/homepage/brand/Toss_Symbol.zip). `public/assets/toss-symbol-tight.png`는 투명 여백을 정리한 자산입니다. |
| Toss Income 로고 | [공식 계열사 다운로드](https://static.toss.im/assets/homepage/brand/2026-CI/TossIncome.zip). `public/assets/toss-income-tight.png`에 사용합니다. |
| 명함 앞·뒷면 SVG/PNG | 소유자가 제공한 실물 명함을 바탕으로 재구성했습니다. 원본 사진은 포함하지 않습니다. 위 로고와 개인 연락처를 포함합니다. |
| OG · favicon | 위 자산으로 만든 파생 이미지입니다. |
| README 화면 캡처 | 이 저장소의 실제 로컬 빌드. 개인 연락처와 위 브랜드 자산이 화면에 포함됩니다. |

Toss 브랜드 자산은 [공식 사용 규정](https://brand.toss.im/)을 따릅니다.
공식 다운로드 제공을 자유로운 재배포·수정 허가로 간주하지 않습니다.
상표·로고와 개인 명함 콘텐츠에는 PIP의 MIT 라이선스가 적용되지 않습니다.
앱 소스 자체에는 현재 별도의 오픈소스 라이선스를 부여하지 않았습니다.
